If you've ever used remote desktop

Apps stuck in a remote screen?
Pull them out.

Remote desktop squeezes another Mac's entire screen into a single window. Connect to your home iMac and your work MacBook Pro at once, and you get two screens inside your screen — plus three menu bars and three Docks. DeskWrap pulls out just the windows of the app you need and opens them on this Mac, right in your Dock and ⌘Tab like any other app.

// FAQ

Questions?

How is this different from remote desktop?

Remote desktop shows another Mac's entire screen in a single window. DeskWrap opens only the windows of the apps you pick, one by one, as windows on this Mac — so you keep one menu bar, one Dock and one ⌘Tab: this Mac's.

What if I need the whole screen?

DeskWrap works one app at a time. If you need another Mac's entire desktop, the Screen Sharing app built into macOS is the better fit.

Do I need an internet connection?

Being on the same Wi-Fi is enough. To use it away from home, connect the two Macs with a VPN such as Tailscale.

Do both Macs need to be on?

The Mac running the app has to be on. The Mac you're using just shows its windows.

Which Macs does it run on?

Macs with Apple silicon (M1 or later). The Mac you use needs macOS 15 or later, and the Mac running the apps needs macOS 15.2 or later.

Does it work on iPad or Windows?

For now it's Mac only. We're working on other devices.

# DeskWrap

DeskWrap brings the apps running on your other Macs to the Mac in front of you — just the app windows, not the whole remote screen. Each remote app gets its own Dock icon, ⌘Tab entry and menu bar, as if it were installed on this Mac.

- Website: https://deskwrap.rivonlabs.com/en/

DeskWrap is launching soon. It runs on Macs with Apple silicon and macOS 15 or later (the Mac that runs the apps needs macOS 15.2 or later).
